# 待办事项（Todo List）后端 API 开发文档

## 概述
本文档基于前端 Vue 组件 TodoList.vue 的需求，描述后端 Go 代码需要实现的 API 接口。所有 API 使用 JSON 格式，基础路径为 `/v1/todo`。

## 数据模型
每个待办事项（Todo）包含以下字段：
- `id` (int): 唯一标识符
- `title` (string): 待办事项标题
- `status` (bool): 完成状态（true 为已完成，false 为未完成）

## API 接口

### 1. 获取所有待办事项
- **端点**: `GET /v1/todo`
- **描述**: 返回所有待办事项列表
- **响应**:
  - 状态码: 200
  - 内容: JSON 数组，示例:
    ```json
    [
      {
        "id": 1,
        "title": "示例任务",
        "status": false
      }
    ]
    ```

### 2. 更新待办事项状态
- **端点**: `PUT /v1/todo/{id}`
- **描述**: 根据 ID 更新待办事项的完成状态
- **请求体**:
  ```json
  {
    "status": true
  }
  ```
- **响应**:
  - 状态码: 200 (成功)
  - 内容: 无（前端本地更新状态）

### 3. 删除待办事项
- **端点**: `DELETE /v1/todo/{id}`
- **描述**: 根据 ID 删除待办事项
- **响应**:
  - 状态码: 200 (成功)
  - 内容: 无（前端本地移除项）

### 4. 添加新待办事项
- **端点**: `POST /v1/todo`
- **描述**: 创建新的待办事项
- **请求体**:
  ```json
  {
    "title": "新任务标题"
  }
  ```
- **响应**:
  - 状态码: 200 (成功)
  - 内容: 无（前端重新获取列表）

## 错误处理
- 所有 API 在失败时返回适当的 HTTP 状态码（如 400, 404, 500）和错误消息 JSON。
- 示例错误响应:
  ```json
  {
    "error": "描述错误信息"
  }
  ```
